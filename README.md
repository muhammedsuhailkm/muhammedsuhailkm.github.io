# muhammedsuhailkm.github.io

Personal portfolio of Muhammed Suhail, served by GitHub Pages from `index.html`.

`index.html` is a build output. The source is the React + TypeScript + Tailwind + shadcn/ui app in `app/`.

- Edit the content in `app/src/data.ts`, the layout in `app/src/App.tsx`, and the styles in `app/src/index.css`.
- Rebuild with `./app/build.sh` (needs Node and pnpm). It bundles the app into the single `index.html` at the repo root.
- Images and the CV sit outside the bundle in `assets/img/` and `CV-MuhammedSuhail.pdf`.
